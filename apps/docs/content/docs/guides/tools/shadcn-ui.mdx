[shadcn/ui](https://ui.shadcn.com/docs/monorepo) is an open-source set of beautifully designed components made with Tailwind CSS that you can copy and paste into your apps.

To get started with shadcn/ui in a new monorepo, run:

<PackageManagerTabs>

<Tab value="pnpm">

```bash title="Terminal"
pnpm dlx shadcn@latest init
```

</Tab>

<Tab value="yarn">

```bash title="Terminal"
npx shadcn@latest init
```

</Tab>

<Tab value="npm">

```bash title="Terminal"
npx shadcn@latest init
```

</Tab>

<Tab value="bun">

```bash title="Terminal"
bunx shadcn@latest init
```

</Tab>

<Tab value="nub">

```bash title="Terminal"
nubx shadcn@latest init
```

</Tab>

<Tab value="aube">

```bash title="Terminal"
aubx shadcn@latest init
```

</Tab>

</PackageManagerTabs>

When prompted, select the option for monorepos.

<PackageManagerTabs>
