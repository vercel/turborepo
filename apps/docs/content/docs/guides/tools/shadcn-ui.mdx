[shadcn/ui](https://ui.shadcn.com/docs/monorepo) is an open-source set of beautifully designed components made with Tailwind CSS that you can copy and paste into your apps.

The shadcn/ui CLI understands the structure of a monorepo. Run it from the root of your repository and point the `-c` flag at the workspace that will use the components. The CLI installs the components, their dependencies, and their registry dependencies in the right place.

To initialize shadcn/ui in a workspace, run:

<PackageManagerTabs>

<Tab value="pnpm">

```bash title="Terminal"
pnpm dlx shadcn@latest init -c apps/web
```

</Tab>

<Tab value="yarn">

```bash title="Terminal"
npx shadcn@latest init -c apps/web
```

</Tab>

<Tab value="npm">

```bash title="Terminal"
npx shadcn@latest init -c apps/web
```

</Tab>

<Tab value="bun">

```bash title="Terminal"
bunx shadcn@latest init -c apps/web
```

</Tab>

<Tab value="nub">

```bash title="Terminal"
nubx shadcn@latest init -c apps/web
```

</Tab>

<Tab value="aube">

```bash title="Terminal"
aubx shadcn@latest init -c apps/web
```

</Tab>

</PackageManagerTabs>

Replace `apps/web` with the workspace that should use the components. You can also run the command from inside that workspace and leave off the `-c` flag.

## More information

To learn more about using shadcn/ui in a monorepo, [visit the docs for shadcn/ui](https://ui.shadcn.com/docs/monorepo).

To scaffold a new monorepo with shadcn/ui already configured, run `shadcn@latest init --monorepo` and select a template.
