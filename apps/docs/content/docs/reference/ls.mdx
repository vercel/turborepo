List packages in your monorepo.

```bash title="Terminal"
turbo ls [package(s)] [flags]
```

When scoped to the entire repository, output includes package manager, package count, and all package names and directories.

```bash title="Terminal"
# List all packages in the repository
turbo ls
```

When scoped to one or more packages, output includes package name, directory, internal dependencies, and all tasks.

```bash title="Terminal"
# List only two packages
turbo ls web @repo/ui [package(s)]
```

## Flags

### `--affected`

Automatically filter to only packages that are affected by changes on the current branch.

When combined with `--filter`, returns the intersection: only packages that are both affected **and** match the filter.

```bash title="Terminal"
turbo ls --affected
turbo ls --affected --filter=web
```

By default the changes considered are those between `main` and `HEAD`.

- You can override the base with `--base` or `TURBO_SCM_BASE`.
- You can override the head with `--head` or `TURBO_SCM_HEAD`.

When both a CLI flag and its environment variable are provided, the CLI flag takes precedence.

```bash title="Terminal"
turbo ls --affected --base=development --head=HEAD
TURBO_SCM_BASE=development turbo ls --affected
```

#### `--base`

Base git ref for `--affected` comparison. Defaults to the auto-detected base (e.g. `GITHUB_BASE_REF` on GitHub Actions, or the merge-base with `main`).

Can also be set with the `TURBO_SCM_BASE` environment variable. When both are provided, `--base` takes precedence.

```bash title="Terminal"
turbo ls --affected --base main
```

#### `--head`

Head git ref for `--affected` comparison. Defaults to `HEAD`.

Can also be set with the `TURBO_SCM_HEAD` environment variable. When both are provided, `--head` takes precedence.

```bash title="Terminal"
turbo ls --affected --head my-branch
```

### `--output <format>` <ExperimentalBadge />

Format to output the results. `json` or `pretty` (default)

```bash title="Terminal"
turbo ls --output=json
```
