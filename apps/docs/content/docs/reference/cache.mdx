```bash title="Terminal"
turbo cache <subcommand>
```

Manage cached task artifacts.

## Subcommands

### `list`

```bash title="Terminal"
turbo cache list
```

Alias: `turbo cache ls`

Show the 10 most recently cached task artifacts in the local filesystem cache, newest first. The local cache directory is set by [`cacheDir`](/docs/reference/configuration#cachedir) or [`TURBO_CACHE_DIR`](/docs/reference/system-environment-variables#turbo_cache_dir).

```txt title="Terminal"
HASH              CACHED AT
2f1e0d9c8b7a6543  2026-10-06 14:03:12
```

`CACHED AT` is the time, in your local time zone, when the artifact was written to this machine's local cache. That is either when the task ran, or when the artifact was downloaded from [Remote Cache](/docs/core-concepts/remote-caching). Restoring a cache hit does not update it.

Use a hash from this list with [`turbo cache push`](#push) to upload that artifact to Remote Cache.

### `push`

```bash title="Terminal"
turbo cache push <hash...> [--upload-timeout <seconds>]
```

Upload task artifacts from the local filesystem cache to [Remote Cache](/docs/core-concepts/remote-caching). Use this to share a build that ran without Remote Cache access, or whose upload failed during `turbo run`.

Each argument is a task hash. You can find task hashes in the `cache miss, executing <hash>` log line, in [run summaries](/docs/reference/run#--summarize), or with a dry run:

```bash title="Terminal"
turbo run build --filter=web --dry=json | jq -r '.tasks[].hash'
```

`turbo cache push` uploads the archive exactly as it is stored in the local cache. It keeps the task duration and the git commit information recorded when the task ran. If [artifact signing](/docs/core-concepts/remote-caching#artifact-integrity-and-authenticity-verification) is enabled, each artifact is signed with `TURBO_REMOTE_CACHE_SIGNATURE_KEY` before upload.

Before uploading anything, `turbo` checks that every hash exists in the local cache, that the repository is [linked](/docs/reference/link) to Remote Cache, and that Remote Cache writes are allowed. The command fails if remote caching is disabled with [`remoteCache.enabled`](/docs/reference/configuration#enabled), or if writes are disabled with [`TURBO_REMOTE_CACHE_READ_ONLY`](/docs/reference/system-environment-variables#turbo_remote_cache_read_only) or [`TURBO_CACHE`](/docs/reference/system-environment-variables#turbo_cache).

Artifacts are uploaded one at a time. If an upload fails, `turbo` continues with the remaining hashes and exits with a non-zero code.

#### `--upload-timeout <seconds>`

Default: `60`

The time in seconds allowed for each artifact upload. Use `0` to disable the timeout. Increase this value for large artifacts or slow connections.

```bash title="Terminal"
turbo cache push 2f1e0d9c8b7a6543 --upload-timeout=300
```

This flag takes precedence over [`TURBO_REMOTE_CACHE_UPLOAD_TIMEOUT`](/docs/reference/system-environment-variables#turbo_remote_cache_upload_timeout) and [`remoteCache.uploadTimeout`](/docs/reference/configuration#uploadtimeout). The global `--remote-cache-timeout` flag still applies to connecting and to other Remote Cache requests.
