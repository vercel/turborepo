## Installing `turbo`

You can install `turbo` globally and pin a version in your repository. When a local binary is installed, the global binary defers to it.

### Global installation

A global install of `turbo` brings flexibility and speed to your local workflows.

<Tabs items={["macOS and Linux", "Windows x64"]}>
  <Tab value="macOS and Linux">

```sh title="Terminal"
curl -fsSL https://turborepo.dev/install | sh
```

  </Tab>
  <Tab value="Windows x64">

```powershell title="PowerShell"
irm https://turborepo.dev/install.ps1 | iex
```

  </Tab>
</Tabs>

<Callout type="info">
  See the [support policy](/docs/support-policy#platforms) for supported platforms.
</Callout>

<Callout type="info">
  The binaries are also available directly in the [GitHub release assets](https://github.com/vercel/turborepo/releases), starting with 2.11.5. To install an older version, use your package manager.
</Callout>

After installing `turbo`, you can run commands from your terminal. For example:

- `turbo build`: Run `build` scripts following your repository's dependency graph
- `turbo build --filter=docs --dry`: Quickly print an outline of the `build` task for your `docs` package (without running it)
- `turbo generate`: Run [Generators](/docs/guides/generating-code) to add new code to your repository
- `cd apps/docs && turbo build`: Run the `build` script in the `docs` package and its dependencies. For more, visit the [Automatic Package Scoping section](/docs/crafting-your-repository/running-tasks#automatic-package-scoping).

<Callout type="info">
  `turbo` is an alias for [`turbo run`](/docs/reference/run). For example,
  `turbo build` and `turbo run build` will both run your `build` task.
</Callout>

#### Using global `turbo` in CI

To use the global binary in CI, see [Constructing CI](/docs/crafting-your-repository/constructing-ci#global-turbo-in-ci).

#### Uninstalling global `turbo`

On macOS and Linux, run the installer with `--uninstall` (or set `TURBO_UNINSTALL=1`). If you installed with `--install-dir` or `TURBO_INSTALL_DIR`, pass the same directory.

```sh title="Terminal"
curl -fsSL https://turborepo.dev/install | sh -s -- --uninstall
```

Uninstalling removes only what the installer added: the `turbo` binary in the install directory, plus the lines it marked in your shell profiles with `# Turborepo standalone installer PATH` and `# Turborepo standalone installer shell hook`. If you haven't edited those lines, your profiles return to what they contained before you installed. Other `turbo` installations, symlinks, and lines you wrote yourself stay in place, and the installer reports what it removed and what it left.

On Windows, run the installer with `-Uninstall` (or set `TURBO_UNINSTALL=1`). If you installed with `-InstallDirectory` or `TURBO_INSTALL_DIR`, pass the same directory.

```powershell title="PowerShell"
& ([scriptblock]::Create((irm https://turborepo.dev/install.ps1))) -Uninstall
```

Uninstalling removes only what the installer added: `turbo.exe` in the install directory, the directory and its user `PATH` entry once nothing else is in it, and the line marked `# Turborepo standalone installer shell hook` in your Windows PowerShell and PowerShell 7 profiles. If you haven't edited that line, your profiles return to what they contained before you installed. Other `turbo` installations, other files, and lines you wrote yourself stay in place, and the installer reports what it removed and what it left.

### Repository installation

To pin the `turbo` version used in a repository, add it as a `devDependency` at the root:

<PackageManagerTabs>

  <Tab value="pnpm">
    ```bash title="Terminal"
    pnpm add turbo --save-dev --ignore-workspace-root-check
    ```

  </Tab>

  <Tab value="yarn">
    ```bash title="Terminal"
    yarn add turbo --dev --ignore-workspace-root-check
    ```

  </Tab>

  <Tab value="npm">
  ```bash title="Terminal"
  npm install turbo --save-dev
  ```

  </Tab>

  <Tab value="bun">
  ```bash title="Terminal"
  bun install turbo --dev
  ```

  </Tab>

  
<Tab value="nub">
  ```bash title="Terminal"
  nub add turbo --save-dev
  ```

  </Tab>

<Tab value="aube">
  ```bash title="Terminal"
  aube add turbo --save-dev
  ```

  </Tab>

</PackageManagerTabs>

When you invoke the global binary from this repository, it uses the installed local version instead.
