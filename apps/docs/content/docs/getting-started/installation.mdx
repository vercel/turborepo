## Installing `turbo`

`turbo` can be installed both globally **and** in your repository. We highly recommend installing both ways so you can take advantage of fast, convenient workflows _and_ a stable version of `turbo` for all developers working in your repository.

### Global installation

Install the standalone `turbo` binary globally. This method does not require Node.js or a package manager.

<Tabs items={["macOS and Linux", "Windows"]}>

<Tab value="macOS and Linux">

```bash title="Terminal"
curl -fsSL https://turborepo.dev/install.sh | sh
```

The installer supports macOS and Linux on x64 and ARM64. It installs `turbo` to `~/.local/bin` and configures `PATH` for future zsh, bash, and POSIX shell sessions. Open a new terminal after installation. Other shells may require you to add `~/.local/bin` to `PATH` manually.

</Tab>

<Tab value="Windows">

```powershell title="PowerShell"
irm https://turborepo.dev/install.ps1 | iex
```

The installer supports Windows on x64. It installs `turbo.exe` to `%LOCALAPPDATA%\Programs\Turborepo\bin` and adds that directory to your user `PATH`. Open a new terminal after installation.

</Tab>

</Tabs>

By default, the installer downloads the latest stable release. To install a specific version, set `TURBO_VERSION` for the process that runs the downloaded script:

<Tabs items={["macOS and Linux", "Windows"]}>

<Tab value="macOS and Linux">

```bash title="Terminal"
curl -fsSL https://turborepo.dev/install.sh | TURBO_VERSION=2.5.0 sh
```

</Tab>

<Tab value="Windows">

```powershell title="PowerShell"
$env:TURBO_VERSION = "2.5.0"
irm https://turborepo.dev/install.ps1 | iex
```

</Tab>

</Tabs>

You can also set `TURBO_INSTALL_DIR` to choose another absolute installation directory.

Once installed globally, you can run your scripts through `turbo` from your terminal, quickly running one-off commands to use within your repository. For example:

- `turbo build`: Run `build` scripts following your repository's dependency graph
- `turbo build --filter=docs --dry`: Quickly print an outline of the `build` task for your `docs` package (without running it)
- `turbo generate`: Run [Generators](/docs/guides/generating-code) to add new code to your repository
- `cd apps/docs && turbo build`: Run the `build` script in the `docs` package and its dependencies. For more, visit the [Automatic Package Scoping section](/docs/crafting-your-repository/running-tasks#automatic-package-scoping).

<Callout type="info">
  `turbo` is an alias for [`turbo run`](/docs/reference/run). For example,
  `turbo build` and `turbo run build` will both run your `build` task.
</Callout>

<Callout type="error" title="Remove existing global installations first">
  The standalone installer stops if `turbo` is already available on `PATH` and
  never replaces an existing executable. Use [`turbo bin`](/docs/reference/bin)
  to locate your current installation, uninstall it with the package manager or
  method that installed it, and then run the standalone installer. Follow the
  same remove-and-reinstall process to upgrade a standalone global installation.
</Callout>

#### Using global `turbo` in CI

You can also take advantage of global `turbo` when creating your CI pipelines. Visit the [Constructing CI](/docs/crafting-your-repository/constructing-ci#global-turbo-in-ci) guide for more information.

### Repository installation

When collaborating with other developers in a repository, it's a good idea to pin versions of dependencies. You can do this with `turbo` by adding it as a `devDependency` in the root of your repository:

<PackageManagerTabs>

  <Tab value="pnpm">
    ```bash title="Terminal"
    pnpm add turbo --save-dev --ignore-workspace-root-check
    ```

  </Tab>

  <Tab value="yarn">
    ```bash title="Terminal"
    yarn add turbo --dev --ignore-workspace-root-check
    ```

  </Tab>

  <Tab value="npm">
  ```bash title="Terminal"
  npm install turbo --save-dev
  ```

  </Tab>

  <Tab value="bun">
  ```bash title="Terminal"
  bun install turbo --dev
  ```

  </Tab>

  
<Tab value="nub">
  ```bash title="Terminal"
  nub add turbo --save-dev
  ```

  </Tab>

<Tab value="aube">
  ```bash title="Terminal"
  aube add turbo --save-dev
  ```

  </Tab>

</PackageManagerTabs>

You can continue to use your global installation of `turbo` to run commands. Global `turbo` will defer to the local version of your repository if it exists.

This lets you to get the best of both installations: easily run commands in your terminal while maintaining a pinned version for consistent usage for all developers in the repository.
