## Getting Started

From the monorepo root, run:

```sh
yarn workspace docs dev
```

Open [http://localhost:3001](http://localhost:3001). Edit `app/page.tsx` in this workspace to update the page. `app/layout.tsx` defines the root layout.

This app uses the Next.js App Router. Add API endpoints with [Route Handlers](https://nextjs.org/docs/app/getting-started/route-handlers), for example `app/api/hello/route.ts`.
