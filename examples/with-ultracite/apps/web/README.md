# Web

A [Next.js](https://nextjs.org) App Router application using the shared `@repo/ui` components.

## Getting Started

Install dependencies with `pnpm install` from the monorepo root, then start this app:

```sh
pnpm --filter web dev
```

Open [http://localhost:3000](http://localhost:3000) to see the result. Edit `app/page.tsx` to update the page.

The app uses [`next/font/local`](https://nextjs.org/docs/app/api-reference/components/font#local-fonts) to load the bundled Geist Sans and Geist Mono fonts without fetching Google Fonts during builds.
