# Turborepo Rsbuild module federation starter

This is a community-maintained example. If you experience a problem, please submit a pull request with a fix. GitHub Issues will be closed.

## Using this example

Use Node.js 26.12.1 or newer and pnpm 12.15.0, as pinned in `package.json`.

```sh
npx create-turbo@latest -e with-rsbuild-module-federation
```

From the generated repository directory, install dependencies with pnpm:

```sh
pnpm install
```

## What's inside?

This Turborepo includes the following packages/apps:

- `react-host`: an [Rsbuild](https://rsbuild.rs/) React host app that consumes the remote app
- `react-remote`: an [Rsbuild](https://rsbuild.rs/) React remote app that exposes `./remote-app`
- `@mf-rsbuild-example/shared-ui`: a React component library shared by both applications

Each package/app is written in [TypeScript](https://www.typescriptlang.org/).
[Module Federation](https://module-federation.io/) composes the host and remote at runtime.

### Build

Build all apps and packages from the repository root:

```sh
pnpm build
```

Build a specific package with a [filter](https://turborepo.dev/docs/crafting-your-repository/running-tasks#using-filters):

```sh
pnpm exec turbo run build --filter=react-host
```

Turborepo builds the shared UI library before either app and caches each package's `dist` output.
The remote is loaded at runtime, so building the host alone does not build the remote.

### Develop

Start both applications:

```sh
pnpm dev
```

Visit `http://localhost:3000`. The host runs on port `3000` and resolves the remote
through `http://localhost:3001/mf-manifest.json`, generated by
`@module-federation/rsbuild-plugin` on port `3001`.

To filter development to the applications, include both runtime participants:

```sh
pnpm exec turbo run dev --filter=react-host --filter=react-remote
```

The shared UI library is built before the development servers start. After changing
its source, run `pnpm exec turbo run build --filter=@mf-rsbuild-example/shared-ui`
to rebuild it.

### Type checking

```sh
pnpm typecheck
```

This checks all three packages, building the shared UI library first so its declarations are available to the apps.

### Preview

Build the applications, then start both production preview servers:

```sh
pnpm build
pnpm preview
```

Open `http://localhost:3000` and keep the remote running on port `3001`.

### Remote Caching

> [!TIP]
> Vercel Remote Cache is free for all plans. Get started at [vercel.com](https://vercel.com/signup?utm_source=turborepo-examples).

Turborepo caches locally by default. To share cache artifacts across machines,
[create a Vercel account](https://vercel.com/signup?utm_source=turborepo-examples),
then authenticate and link your repository from its root:

```sh
pnpm exec turbo login
pnpm exec turbo link
```
